**Proyecto: `Estilo Urbano`**
#Elegimos el sistema de gestión de venta para una tienda de indumentaria.
**Descripción del caso:**
##El comercio posee el nombre de `Estilo Urbano` y se especializa  en la venta minorista de prendas de vestir de uso diario, incluyendo remeras, pantalones, abrigos y accesorios.
Para Optimizar su atención y control interno, el local necesita implementar un sistema informático de gestión de ventas. El sistema se centrará en registrar las transacciones comerciales, mantener una base de datos de los compradores y gestionar de forma precisa el stock de cada prenda, teniendo en cuenta las variaciones de talle y color.
__________________________________
**El Sistema  permite gestionar:**
•**`Clientes`**
•**`Catálogo de Indumentaria`**
•**`Categorías`**
•**`Talles y Colores`**
•**`Stock de las Distintas Variantes`**
•**`Ventas`**
•**`Detalles de las Ventas`**
•**`Metodo de Pago`**
__________________________________
###Ademas, el sistema debe conservar el precio que tenía cada prenda en el momento de realizar la venta para que los cambios posteriores de precio no modifiquen las ventas 
anteriores.
