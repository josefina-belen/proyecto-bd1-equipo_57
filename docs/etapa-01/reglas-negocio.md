RN.01 (Registro de Clientes): Toda venta debe estar asociada a un cliente
registrado en el sistema. Para el alta, es obligatorio ingresar el DNI (identificador
único), nombre y apellido.
RN.02 (Gestión de Stock): Toda prenda comercializada debe contar con un registro
de unidades disponibles. Al confirmar un comprobante, el sistema debe descontar
automáticamente la cantidad adquirida. No se pueden registrar ventas si el stock es
insuficiente
