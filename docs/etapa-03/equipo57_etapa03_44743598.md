### 🤝 Decisiones en las que participé
Participé en la definición de la jerarquía y el orden de creación de las tablas dentro del script SQL, decidiendo crear primero las entidades fuertes. ### ⚠️ Problemas o dificultades Identificadas
El desafío principal fue determinar con precisión qué restricciones de dominio aplicar más allá de las claves primarias, y garantizar que el código de las tablas independientes estuviera libre de errores para que mis compañeros pudieran avanzar sin bloqueos con las tablas dependientes.

### 💡 Soluciones o propuestas realizadas
Se estructuró la cabecera del script DDL priorizando las tablas que no poseían claves foráneas. Se aplicaron estratégicamente las cláusulas UNIQUE y NOT NULL en los campos obligatorios para asegurar que el sistema rechace registros inconsistentes o vacíos desde la base, brindando un cimiento sólido para las dependencias futuras.
